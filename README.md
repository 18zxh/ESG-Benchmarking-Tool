# ESG Benchmarking Tool

面向个人本机使用的 ESG 知识库与报告评估工作台。当前应用版本 **0.5.3**；首次 V1 基线为 0.4.0。

集成 CSA、MSCI、大陆交易所、港交所及横向对标五个模块，保留各体系原有的知识库、表单和评估方法。共用入口、模型连接、PDF 基础设施和本机存储，不把不同评级体系合并成一种分数。

## 安装与启动（macOS）

1. 下载本仓库源码并解压到固定目录，安装 **Python 3.12**。
2. 首次双击根目录 **初始化统一ESG工作台.command**，安装独立运行环境和固定依赖。
3. 双击 **启动统一ESG工作台.command**，浏览器打开工作台。默认地址为 `http://127.0.0.1:8791/`；端口占用时自动顺延。
4. 若终端提示没有执行权限，在解压目录执行：

```sh
chmod +x *.command
./初始化统一ESG工作台.command
./启动统一ESG工作台.command
```

本版附带构建好的界面，日常使用不需要 Node.js。关闭启动窗口会停止服务。当前已验证本机 macOS；另一台全新电脑尚待验证。

## 使用

- **项目中心**：新建、打开、改名、搜索、模块筛选与分页。删除进入回收站，可撤销或恢复；报告、结果与评论保留。运行任务中的项目不允许删除。
- **保存与继续**：在原工作台点击保存，自动登记项目并同步企业、覆盖期间和时间；再次从项目中心打开会自动恢复草稿与原 PDF。新建时填写的企业和期间会带入工作台。
- **各标准 / 各交易所**：CSA、MSCI、大陆与香港保留各自的范围选择、上传、AI 初评、人工复核及 Excel 导出。期间按报告内容填写，不根据文件名或发布日期推断。
- **横向对标**：多家公司报告按同一议题、四要素与二级检查项比较；未完成不计作未披露，覆盖率排除本公司。暂不提供绩效数值对标。
- **资料库**：独立登记原 PDF、企业、实际覆盖期间、类型和公开来源。评估仍使用各工作台的上传入口。
- **设置**：登记共享 GLM 连接、下载完整备份、查看各体系方法来源。方法更新仍需核对来源与年度，当前没有自动抓取和发布方法的功能。

## 模型、数据与备份

支持共享 GLM 连接，以及兼容 OpenAI 接口的 CPA 本机代理（可配置 Base URL、模型、密钥和推理强度）。CPA 代理需另行安装配置，本仓库不附带代理程序或账号凭据。GLM 实测模型为 `glm-5.3-flash`。模型密钥仅存服务进程内存，重启后重新连接。执行 AI 任务时，所选 PDF 请求副本、适用方法和相关证据会发送到已配置的模型服务；本机部署不代表模型推理完全离线。

- 本机项目资料：`.runtime/unified-data/workbench.sqlite3`。
- PDF/二进制原件：`.runtime/unified-data/originals/`，按 SHA-256 校验和去重；原件不加页码、不覆盖。
- 运行环境：`.runtime/unified-python/`。
- 备份：使用设置中的“下载完整本机备份”，避免运行时单独复制 SQLite 而遗漏事务。

恢复只写入新的、尚不存在的目录，不覆盖已有数据：

```sh
.runtime/unified-python/bin/python -m unified.backup restore /完整路径/备份.zip --target /完整路径/新资料目录
.runtime/unified-python/bin/python -m unified.server --port 8791 --data-dir /完整路径/新资料目录 --open-browser
```

旧版浏览器草稿不会自动搬移或删除。CSA 可用原“恢复备份”功能导入 JSON；JSON 缺原 PDF 时需重新关联。完整资料迁移使用整库备份。

## 架构与维护

| 路径 | 职责 |
| --- | --- |
| `unified/web/src/` | React / TypeScript 入口、项目中心、资料库与设置 |
| `unified/app-dist/` | 可直接运行的生产界面、PDF 查看字体及许可 |
| `unified/site/` | 原版共用导航、样式和保存兼容层 |
| `unified/modules/` | 固定来源的三套原版代码与公开方法资料 |
| `unified/server.py` | Python 3.12 单进程、单端口服务与运行时适配 |
| `unified/project_center.py` | 项目生命周期、回收站、版本冲突及原草稿索引 |
| `unified/core.py` / `backup.py` | SQLite、原件、历史、缓存和完整备份 |
| `unified/gateway.py` / `adapters.py` | 内存连接、共享模型传输与原验证器适配 |
| `unified/pdf_engine.py` / `csa_windows.py` | PDF 请求副本、首页预检、分批与完整证据窗口 |
| `unified/upstream.json` | 上游固定提交与文件指纹；本发布排除项见发布清单 |

源码变更后在 `unified/web/` 构建：

```sh
npm ci --ignore-scripts
npm run build
```

构建已使用 Node 22.23.2 / npm 10.9.8 验证。固定依赖见 lock 文件；第三方许可见 `unified/web/THIRD_PARTY_NOTICES.md` 和构建目录许可文件。原版适配保留各体系方法；旧统一评估页及方法发布代码仅作历史兼容，不是当前产品入口。

## 首次 V1 的历史验证和限制

发布基线通过 53 项 Python 模拟回归、4 项 Node 导出检查及 TypeScript/Vite 构建。浏览器使用合成 PDF 验证五个模块上传、保存和重新打开；验证改名、删除、撤销、回收站恢复、直接保存登记与版本冲突提示，并检查桌面与390px模拟窄屏。

这些检查不等于真实收费模型、整本企业报告准确性或完整评分认证。AI 初评需要人工复核；不输出任何机构的官方评分。真实长报告识别、成本和耗时仍需使用授权样本另行验证。

本仓库包含运行代码、生产界面、公开方法资料和维护说明；不包含个人项目、客户报告、密钥、运行环境、缓存、备份、开发截图、测试及本机历史记录。公开方法资料仅供来源追溯，权利归原发布机构；第三方组件遵循随附许可。未对第三方资料另行授予许可。

## 0.5.3 更新与当前验证（2026-10-21）

GLM 流式响应有大小和时间边界，同进程请求串行；余额不足停止后续请求。PDF 优先使用可靠文字层，按原文锚点回填物理页与引文；读取失败不作未披露处理。暂停、停止、失败重试及已验证页/窗口复用均保留结果。MSCI 与 CSA 补充同源 PDF 文字流，减少双栏角色混读；公司数值和单位须有本项直接引文支持。

MSCI 在预算内综合全部窗口，CSA 对错误单题定向修复，交易所按完整预算分组合并。修复 CSA 解码后文件数据已释放导致的文字流异常、重复上传临时 ID 引起的缓存失效及摘要夹带内部引用编号等问题。

123 项自动回归通过。授权西南证券 GLM 实测中，三个模块均读完 59 物理页：MSCI 141 项、CSA 106 个可启用问题、内地上交所主板 19 项形成初评，循环经济与科技伦理两项缺映射保留待核验。部分结果经过定向修复；引文匹配和数字校验不等于全部判断语义正确。CSA 未提供公开报告 URL，公开来源警告及人工复核状态保留；FBN 为业务测试口径，没有官方行业分配认证。港股和横向对标本轮未实测。所有结果均为辅助初评，须人工复核，不生成官方评级。

发布仅包含程序、生产界面、启动脚本、公开方法资料与发布说明。测试代码、真实企业报告/初评结果、用量明细、备份和本机历史均未上传。完整文件清单见 RELEASE-MANIFEST.json。
