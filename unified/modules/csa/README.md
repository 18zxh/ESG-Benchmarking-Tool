# CSA ESG Workbench · V1

**CSA 方法知识库与报告披露评估工作台。** 查阅行业要求，上传 ESG 报告、年报及佐证 PDF，生成带原文和页码的披露初评，再保存人工备注、导出 Excel。

这是本仓库的首个发布版本。当前方法范围为 **2026 Full CSA**，覆盖 **62 个行业**，随库提供 **85 份方法及参考 PDF**。本工具用于披露准备，初评不代表 S&P Global 官方分数。

## 能做什么

| 模块 | 用途 |
| --- | --- |
| 方法文件导读 | 按文件理解方法、术语和适用范围，打开原始 PDF |
| 行业评分权重 | 手动选择行业、比较权重并导出；行业须由使用者确认 |
| 问题与证据要求 | 按行业、维度和标准查看中文主问题、英文原文及方法依据，导出问题表 |
| 报告评估工作台 | 上传 PDF、生成披露初评、对照原文、保存人工备注和导出成果 |
| 资料与版本 | 分类查看公开方法资料、行业 Handbook、年度变化和 MSA 来源 |

## 快速开始

### 环境

- **macOS + Python 3**，建议 Python 3.12；首次准备依赖需要联网。
- PDF 图像文字识别依赖 macOS PDFKit / Vision。仓库附 Apple Silicon 识别器；其他 Mac 需具备重新编译所需的命令行开发工具。
- 页面使用原生浏览器模块，无需安装 Node 或前端构建工具。

### 启动

1. 克隆或下载本仓库，解压到本机。
2. 双击根目录的 **启动 CSA 工作台.command**，按提示准备依赖。
3. 在浏览器打开 **http://127.0.0.1:8781/**，使用期间保持启动窗口运行。

也可手动启动：

```bash
git clone https://github.com/18zxh/CSA_ESG_Workbench.git
cd CSA_ESG_Workbench
python3 -m venv .runtime
.runtime/bin/python3 -m pip install -r pipeline/requirements.txt
.runtime/bin/python3 pipeline/workbench_server.py --port 8781 --open-browser
```

这是本机应用，GitHub 保存源码和方法资料。直接打开 `site/index.html` 或仅部署静态页面，不能替代 PDF 识别、模型调用和下载所需的 Python 服务。

## 三步使用

1. **上传与范围**：填写企业名称、已确认的 CSA 行业和报告实际覆盖期间，上传主报告及可选佐证。发布日期不能代替报告期间；公开来源与资料类型请据实填写。
2. **披露初评**：在“模型连接设置”中填写自己的 GLM API Key。默认模型为 `glm-5.3-flash`，可选 `glm-5.3-flashx`；只支持官方 GLM 接口。连接后，原 PDF 按连续物理页分段发送至所选模型，逐页检索并核对摘录，再按完整方法生成初评。
3. **人工复核与导出**：对照原 PDF，添加并保存人工备注，再导出 Excel。未保存的备注草稿不会进入成果表。

主要报告与佐证合计最多 6 份，每份 1–500 页。本机上传上限为 80 MB；**GLM 原生 PDF 初评单份上限为 50 MB**。未连接模型时仅提供本机候选原文。

## 保存、续跑与数据去向

- 原 PDF、项目和人工意见保存在当前浏览器的本机存储。不同浏览器或端口使用独立存储。
- 定期下载项目 JSON 备份，并另行保留原 PDF。JSON 不含原 PDF 或模型密钥；恢复后需重新关联同一文件。
- API Key 仅保存在本机服务内存，服务重启后需重新连接；仓库不提供或内置密钥。
- PDF 读取会将原 PDF 发送至使用者配置的 GLM 服务。SQLite 断点与证据缓存保留本机，不随代码上传。
- 默认“继续初评”复用匹配的已完成题目和页段；新增题目仍需检索，新报告仍需阅读。暂停或取消在请求边界生效，已发送的调用仍可能计费。
- “继续与重新评估”可选择只重新生成初评，或重新阅读原 PDF。重跑保留人工意见；资料变更后的旧结论会标记待更新。

缓存、清理和故障恢复细节见 [运行规则](docs/RUNTIME.md)。

## 方法与使用边界

行业方法 Excel 和传给 AI 的完整方法记录共用 `assessment-method-schema.json`，保留中英文方法、选项与条件。页面的简洁主问题不能替代完整评估依据；报告证据和项目背景是另外的输入。

中文为阅读辅助，具体条件以英文母本及企业适用的门户问卷为准。未取得的线上动态分支与官方问题级评分规则，不推断或编造。原文定位、页码和范围校验能发现部分错误，不能保证模型理解、表格关系或证据召回没有遗漏。

**当前限制：完整真实企业报告的新旧流程对照尚未完成，V1 不承诺全题准确率、首次评估费用或 Token 节省比例。** 官方方法 PDF 及参考示例的权利归原发布方；它们不是企业评级结论。
