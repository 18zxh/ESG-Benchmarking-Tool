## 2. 使用与数据

按README在macOS启动8781本机服务。确认企业行业、方法年度与报告期间，上传PDF后连接自己的GLM，再进行初评、原文对照和人工加备注。模型只允许GLM-5.3-Flash系列，默认`glm-5.3-flash`。

项目及原PDF保存在当前浏览器；备份JSON不包含原PDF或密钥，换浏览器需恢复JSON并关联相同原文件。人工已保存意见与模型草稿分开，模型重跑不会覆盖人工意见或未保存草稿；Excel只输出已保存意见。

当前浏览器已有项目不因仓库迁移删除。本机地址/端口改变会进入另一份浏览器存储，迁移前先备份。

## 3. 方法与评估

完整方法字段契约为`site/data/assessment-method-schema.json`。前端`assessment-method.js`与后端`csa_adapter.py`从相同字段定义生成方法Excel和AI方法对象；页面一级主问题只负责易读展示。证据、项目背景另作上下文，不属于方法Excel字段。

方法依据为公开英文母本，中文仅作阅读辅助。适用行业和证据要求须有来源；不能按企业名称推断官方行业，也不能编造未披露数据、门户动态分支或官方分值。V1不输出标普官方评级分数。

## 4. PDF链路与恢复

模型按连续物理页阅读原PDF，检查请求范围和返回页码；摘录需匹配同一物理页的连续原文，再进入逐题初评。输出截断、缺页、超限或校验失败时拆小或保留待核实，不写成企业未披露。OCR、表格关系及证据召回仍需人工核对。

SQLite保存成功页段、逐题覆盖、拆分决策、合格题结果与已知usage。复用键包含企业/行业、PDF内容、完整方法、模型/服务与源码合同。新增题目不自动获得已读资格；新增报告只阅读新文件，增删报告后保守重评当前题目。来源/公开性/期间变更会使相关初评失效，保留历史草稿和人工意见。

重新启动后连接GLM、关联原文件，选择“继续初评”。暂停/取消在请求边界执行；相同活跃请求附着原任务。完整缓存命中不重复进行全文定位或调用模型。无供应商usage的失败请求不能视为零费用。

## 6. 维护顺序

1. 更新英文原始方法和来源，明确年度、行业及版本；保留原文页码。
2. 同步题库、中文辅助、权重、模板及启用条件。同名题目只有完整依据一致时才共用，行业差异单独保留。
3. 变更方法字段时同时核对前端Excel和后端AI规范方法对象，逐行业/逐字段比较，不能只比一级标题。
4. 修改服务后重启；源码/方法/模型变更按合同失效，不能将旧缓存强行当新版本完成。
5. 修改保存/人工备注/导出或PDF链路后，使用另行保留的开发验证材料核对相关流程，再更新发布清单。原始测试文件不放入运行版。
6. 提交前检查密钥、企业资料、缓存与环境排除；上传后核对远端完整路径、Git对象及权限。

模块入口见架构说明，其他评级接入见复用指南。共享存储可以复用；CSA题库、证据判定、提示词和导出语义仍属本评级。第二个工作台尚未接入，不宣称完整通用引擎已发布。

## 7. 更新与回退

先保存项目JSON、原PDF和人工意见，再更新代码并重启服务。缓存可通过运行配置关闭或在无活跃任务时清理；清理不删除浏览器项目。回退使用上一个明确提交或独立副本，保留用户未提交修改，不对用户工作目录进行整体reset/clean。原始公开PDF的权利归发布方。
