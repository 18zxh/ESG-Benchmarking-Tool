# V1 运行规则

## 启动与模型

macOS、Python3；首次依赖安装需要网络。双击根目录启动文件，使用`http://127.0.0.1:8781/`。终端启动命令见README。网站运行无需Node。图像文字定位依赖PDFKit/Vision；附Apple Silicon识别器及源码/指纹，其他Mac需本机开发工具重新编译。

GLM连接由用户设置，只允许官方GLM HTTPS接口和GLM-5.3-Flash系列；默认`glm-5.3-flash`，可选`glm-5.3-flashx`。密钥仅在服务内存，重启后重新连接，不保存到项目或仓库。调用会向所选GLM服务发送原PDF分段及评估所需方法/背景/证据。

主报告与佐证合计最多6份，每份1–500页。本机上传不超过80MB，原生GLM初评不超过50MB/份；一次模型评估最多160题。不得把失败或未读页面标成未披露。

## 保存与恢复

- 项目、原PDF和人工意见保存在当前浏览器本机存储，不同端口或浏览器独立。
- 经常下载项目JSON并另外保留原PDF；恢复JSON后关联相同文件，不能假定备份已包含PDF。
- 人工意见先保存再导出Excel；草稿保留在项目里但不作已确认意见导出。
- 服务重启需重新连接GLM，再通过“继续初评”复用已完成范围。
- 修改资料/选题后，过期结论标记待更新；人工已保存意见和未保存草稿保留。

## 缓存与控制

默认缓存路径：`~/Library/Application Support/CSA-评级工作台/pipeline-cache.sqlite3`。包含公司原文与任务结果，按本机项目资料管理，不随源码共享。缓存条目默认30天、256MiB逻辑容量；任务及usage另按30天保留。原PDF和密钥不存入此数据库。

| 环境变量 | 用途 |
| --- | --- |
| `WORKBENCH_CACHE_PATH` | 独立SQLite文件路径 |
| `WORKBENCH_CACHE_MB` | 条目逻辑容量，默认256MiB |
| `WORKBENCH_CACHE_DAYS` | 保留天数，默认30 |
| `WORKBENCH_CACHE_ENABLED=0` | 关闭读取/初评复用；兼容`CSA_PDF_CACHE=0` |
| `WORKBENCH_COMPACT_ENABLED=1` | 选择性启用共用证据表；默认关闭，兼容`CSA_PDF_COMPACT=1` |

环境变量在启动前设置。共用证据表的完整真实报告对照尚未完成，普通使用保持关闭。

“继续与重新评估”支持继续已完成部分、复用原文重新生成初评、重新读取PDF并初评。新增题目/报告仍须实际读取。暂停/取消在下次模型请求前生效，已发送请求可能仍返回并计费。清理缓存仅限无活跃任务时，不删除浏览器项目或人工备注。缓存复用要求相同资料内容、完整方法和相关背景，模型/方法/源码或资料元数据变化会按阶段失效。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| 检测到旧服务 | 保存项目，在原启动窗口Control+C退出，再启动当前代码 |
| 8781被占用 | 关闭占用该地址的程序再启动，不并行开两套服务 |
| 连接失效/密钥未设置 | 在原模型设置中重新连接，不把密钥写入源码 |
| GLM连接中断或额度不可用 | 保留项目和缓存，恢复连接后继续；不能将失败视为企业未披露 |
| 更换浏览器/端口看不到项目 | 回原浏览器导出JSON，在目标浏览器恢复并关联原PDF |
| Excel缺少新写意见 | 先保存人工备注，再重新导出 |
| 引文/OCR需要核实 | 打开原PDF物理页确认，保留待核实标记和人工意见 |

本工具是披露准备辅助，不替代官方门户问卷或人工判断。首次运行仍需完整阅读；不承诺未经完整实测的费用或Token节省比例。
